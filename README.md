# SolidHome — NXP FRDM-MCXN947 Firmware

Embedded microcontroller firmware for the **SolidHome** smart home system, implemented on the **NXP FRDM-MCXN947** evaluation board.

The module is responsible for direct control of output actuator circuits (relays / lighting), reading environmental sensor data, and two-way communication with the central **SolidHomeApi** server over Wi-Fi.
